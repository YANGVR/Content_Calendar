# 06 — 첫 화면: 최신 콘텐츠

## Outcome

로그인한 사용자가 첫 화면에서 TMDB 최신 영화·드라마·애니메이션·예능을 탭으로 나눠 보고, 항목을 눌러 그 콘텐츠 화면에서 바로 기록한다. 내 시청 기록(날짜별 목록·달력)은 메뉴의 "기록" 화면에서 본다.

## Blockers

03 — 첫 화면 항목이 여는 TMDB 콘텐츠 화면과 기록 흐름이 필요하다.

## Acceptance criteria

- [ ] 첫 화면에 영화·드라마·애니메이션·예능 탭이 있고, 탭마다 최신 작품이 포스터·제목·날짜와 함께 보인다. (spec 19)
- [ ] 항목을 누르면 그 콘텐츠 화면이 열리고, 열기만 해서는 "내 콘텐츠"에 저장되지 않는다. (spec 20)
- [ ] 날짜별 목록·달력은 "기록" 메뉴에서 이전과 같이 동작한다. (spec 21)
- [ ] 가입·로그인 후 첫 화면으로 이동한다.

## Constraints

- "최신" 기준과 TV 목록 범위는 spec의 가정을 따른다.

## Verification

- 실행 중인 앱에서 네 탭 모두 결과가 보이고, 각 항목의 종류가 탭과 맞는다.
- 첫 화면 항목을 열고 기록 없이 돌아오면 "내 콘텐츠"에 없다.
- "기록" 화면의 목록과 달력이 기존 기록을 보여준다.
