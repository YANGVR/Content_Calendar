# 02 — 콘텐츠 상세: 평점·한줄평·진행률 + 내 콘텐츠 목록

## Outcome

사용자가 콘텐츠 상세에서 섬네일, 평점(1–5), 한줄평, 진행률, 회차별 기록 여부, 그 콘텐츠의 기록 목록을 보고, 평점과 한줄평을 콘텐츠 단위로 저장·수정·삭제한다. 내가 기록한 콘텐츠 전체를 섬네일·평점·진행률과 함께 모아 본다.

## Blockers

01 — 진행률과 콘텐츠 목록은 시청 기록이 있어야 계산·표시할 수 있다.

## Acceptance criteria

- [ ] 진행률이 "본 회차 수/전체 회차 수화 · N%"로 보이고, 같은 회차를 두 번 기록해도 한 번만 센다. 영화에는 진행률을 표시하지 않는다. (spec 10)
- [ ] 평점 1–5와 한줄평(최대 100자)을 콘텐츠 단위로 저장·수정·삭제할 수 있고, 회차 단위로 매기는 화면은 없다. (spec 11)
- [ ] 내 콘텐츠 목록에 기록한 콘텐츠가 섬네일·평점·진행률과 함께 보인다.
- [ ] "날짜 모름" 기록도 진행률과 콘텐츠 상세 기록 목록에 반영된다. (spec 9)

## Constraints

None.

## Verification

- 16화 콘텐츠에 서로 다른 12개 회차와 중복 1개를 기록하면 "12/16화 · 75%"로 보인다.
- 평점·한줄평 저장 → 새로고침 후 유지 → 수정 → 삭제가 각각 반영된다.
- 다른 계정에서 이 평점·한줄평을 읽거나 고칠 수 없다.
