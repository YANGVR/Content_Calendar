# 05 — 친구 + 공개/비공개

## Outcome

사용자가 아이디로 친구 요청을 보내고, 받은 요청을 수락·거절하고, 보낸 요청을 취소하고, 친구를 삭제한다. 공개 계정인 친구의 날짜별 목록·달력·콘텐츠 목록·상세(평점·한줄평·진행률)를 열람만 한다. 설정에서 공개 범위를 공개/비공개로 바꾼다(기본값 공개).

## Blockers

01, 02 — 친구에게 보여줄 기록, 평점·한줄평·진행률 화면이 있어야 한다.

## Acceptance criteria

- [ ] A가 B에게 요청하고 B가 수락하면 양쪽 친구 목록에 서로가 보이고, 거절·취소하면 친구가 되지 않는다. (spec 13)
- [ ] 공개 계정인 친구의 기록·평점·한줄평과 직접 추가 콘텐츠 이미지를 열람할 수 있고 수정 동작은 없다. 친구가 아닌 계정의 기록은 볼 수 없다. (spec 14)
- [ ] B가 비공개로 바꾸면 친구 A는 B의 기록을 볼 수 없고 "비공개 계정"으로 보이며, 다시 공개로 바꾸면 보인다. (spec 15)
- [ ] 친구를 삭제하면 양쪽 목록에서 사라지고 더 이상 기록을 볼 수 없다. (spec 16)
- [ ] 새로 가입한 계정의 공개 범위는 공개다. (spec 17)

## Constraints

- 친구 관계, 열람 권한, 공개 범위는 [accounts-and-sharing](../../../decisions/accounts-and-sharing.md)를 따른다.

## Verification

- 세 계정(A, B, 친구 아닌 C)으로: C는 A의 기록을 볼 수 없고, B는 A가 공개일 때만 볼 수 있으며, 친구 삭제 후에는 볼 수 없다.
- 데이터 API로 직접 조회해도 화면과 같은 권한이 적용된다.

## Review checkpoint

One review pass after this task. 범위: 작업 01–05의 접근 권한 전체. 위험: 친구가 아닌 사용자나 비공개 계정의 기록·이미지가 데이터 API로 노출되는 권한 실수는 화면 테스트로는 드러나지 않는다.
