# 01 — 콘텐츠 직접 추가 + 시청 기록 + 메인 화면

## Outcome

로그인한 사용자가 콘텐츠를 직접 추가하고(이미지·이름·종류·회차 수), 실제 회차와 시청일(또는 "날짜 모름")을 골라 시청 기록을 남기고 고치고 지운다. 메인 화면에서 날짜별 목록과 월간 달력을 탭으로 오가며 기록을 본다. 가입·로그인 후에는 메인 화면으로 이동한다.

## Blockers

None.

## Acceptance criteria

- [ ] 로그인하지 않은 상태에서 메인·기록·콘텐츠 화면에 접근하면 로그인 화면으로 이동한다. (spec 3)
- [ ] 가입·로그인에 성공하면 메인 화면으로 이동한다.
- [ ] 콘텐츠를 직접 추가하면 추가한 사람만 그 콘텐츠를 찾고 기록할 수 있고, 다른 계정에서는 보이지 않는다. (spec 5)
- [ ] 직접 추가 콘텐츠의 기록 화면에서는 1화~입력한 회차 수만 고를 수 있고, 영화는 회차 없이 기록한다. (spec 6)
- [ ] 회차를 기록하면 해당 날짜의 날짜별 목록과 달력 칸에 섬네일·제목·회차와 함께 나타난다. (spec 7)
- [ ] 기록의 시청일·회차를 바꾸면 목록·달력이 바뀐 값으로 보이고, 삭제하면 모든 보기에서 사라진다. (spec 8)
- [ ] "날짜 모름" 기록은 목록·달력에 없고, 나중에 날짜를 넣으면 나타난다. (spec 9)
- [ ] 같은 회차를 다른 날 다시 기록할 수 있다. (spec 10의 재시청 부분)
- [ ] 달력은 달을 넘길 수 있고, 날짜를 고르면 그날 기록을 보여준다.

## Constraints

- 직접 추가 콘텐츠의 노출 범위와 회차 규칙은 [content-catalog](../../../decisions/content-catalog.md)를 따른다.
- 직접 추가 콘텐츠 이미지는 추가한 사람과, 이후 작업 05에서 그 사람의 기록을 열람하는 친구만 볼 수 있어야 한다. 이번 작업에서는 본인만 보면 된다.

## Verification

- 두 계정으로 실행 중인 앱에서: A가 추가한 콘텐츠·기록·이미지가 B에게 보이지 않는다.
- 기록 추가 → 수정 → 삭제 후 목록과 달력이 각 단계 값과 일치한다.
- "날짜 모름" 기록이 목록·달력에 없다가 날짜 입력 후 나타난다.
- 비로그인 상태로 메인 접근 시 /login으로 이동한다.

## Review checkpoint

One review pass after this task. 범위: 콘텐츠·시청 기록·이미지 저장소의 스키마와 접근 권한. 위험: 이후 모든 작업이 이 구조 위에 쌓이므로, 다른 사용자의 기록·이미지가 노출되거나 남의 기록을 고칠 수 있는 권한 실수가 누적된다.
