# 04 — 필터

## Outcome

사용자가 메인 화면에서 이름(제목 일부), 기간(시작일–종료일), 날짜(하루), 종류 필터를 각각 또는 조합해 기록을 거른다.

## Blockers

01 — 거를 대상인 메인 화면의 날짜별 목록과 달력이 필요하다.

## Acceptance criteria

- [ ] 이름·기간·날짜·종류 필터를 각각, 그리고 조합해 적용하면 목록 결과가 조건에 맞게 줄어든다. (spec 12)
- [ ] 이름·종류 필터는 달력에도 적용된다.
- [ ] "날짜 모름" 기록은 기간·날짜 필터 결과에 나타나지 않는다. (spec 9)

## Constraints

None.

## Verification

- 서로 다른 종류·날짜·제목의 기록을 준비하고 각 필터와 두 개 이상 조합을 적용해 기대한 기록만 남는지 확인한다.
