# 03 — TMDB 검색 연동

## Outcome

사용자가 단어 일부로 TMDB 콘텐츠와 내가 직접 추가한 콘텐츠를 함께 검색하고, TMDB 콘텐츠는 TMDB의 실제 시즌·회차에서 골라 기록한다. 종류는 자동 분류되며 TMDB 출처가 표시된다. 찾는 콘텐츠가 없으면 직접 추가로 이어진다.

## Blockers

01 — 검색한 콘텐츠를 기록할 시청 기록 흐름이 필요하다. 실행에는 사용자가 발급한 TMDB API 키가 필요하다.

## Acceptance criteria

- [ ] 검색어 일부(예: "더 글")로 관련 콘텐츠가 섬네일·제목·종류·연도와 함께 나온다. (spec 4)
- [ ] TMDB 드라마의 기록 화면에서는 TMDB에 있는 회차만 고를 수 있다. (spec 6)
- [ ] 검색 결과에 내가 직접 추가한 콘텐츠도 함께 나오고, 결과가 없을 때 직접 추가로 이어진다.
- [ ] 종류가 spec의 자동 분류 가정대로 매겨진다.
- [ ] TMDB 데이터를 보여주는 화면에 TMDB 출처 표시가 있다. (spec 18)
- [ ] TMDB 콘텐츠를 열어 보기만 하면 "내 콘텐츠"에 나타나지 않고, 처음 기록하면 나타나며 다시 기록해도 하나로 유지된다. (spec 20)

## Constraints

- TMDB 출처, 검색, 회차 규칙은 [content-catalog](../../../decisions/content-catalog.md)를 따르고, API 사용법은 AGENTS.md의 TMDB 문서 지침에 따라 공식 문서를 가져와 확인한다.
- TMDB API 키는 서버에서만 쓰고 브라우저에 노출하지 않는다.

## Verification

- 실제 TMDB 키로 한국어 부분 검색 결과가 나온다.
- TMDB 드라마의 회차 선택지가 TMDB 시즌·회차 목록과 일치하고 시즌 0이 진행률 분모에서 빠진다.
- 브라우저로 전달되는 코드와 응답에 TMDB 키가 없다.
