# 콘텐츠 카탈로그

## Decisions

- 콘텐츠와 회차, 섬네일의 기본 출처는 TMDB API다. 검색은 TMDB의 영화·TV 검색을 한국어 결과로 사용한다.
- 시청 기록의 회차는 실제 회차 중에서 고른다. TMDB 콘텐츠는 TMDB의 시즌·회차 목록, 직접 추가 콘텐츠는 사용자가 정한 회차 수(1화~N화)가 실제 회차다. 자유 입력 회차는 받지 않는다.
- TMDB에서 찾을 수 없는 콘텐츠는 사용자가 직접 추가한다. 직접 추가 콘텐츠는 만든 사람의 검색에만 나타나고, 그 사람의 시청 기록을 열람하는 친구에게는 기록과 함께 보인다.
- TMDB 콘텐츠는 열어 보기만 해서는 저장하지 않고, 사용자가 처음 기록할 때 그 사용자의 콘텐츠로 저장한다. "내 콘텐츠"에는 직접 추가한 콘텐츠와 기록한 TMDB 콘텐츠만 보인다.
- 시즌이 여러 개인 애니메이션은 기수(TMDB 정규 시즌)마다 별도 콘텐츠로 저장·표시한다. 기록·평점·진행률도 기수 단위다. 드라마·예능은 작품 하나 안의 시즌으로 다룬다.
- TMDB 데이터를 쓰는 화면에는 TMDB가 요구하는 출처 표시(승인된 로고와 고지 문구)를 둔다.

## Boundaries

- 직접 추가 콘텐츠를 모든 사용자가 공유하는 공용 카탈로그로 만드는 결정이 아니다.
- TMDB 외의 카탈로그(KOBIS 등)를 병행하지 않는다.

## Why

검색어 부분 일치, 실제 회차 제한, 섬네일을 모두 충족하려면 회차 데이터를 가진 외부 카탈로그가 필요하다. TMDB는 영화·드라마·예능·애니메이션을 한 곳에서 한국어로 제공하고 개인·비상업 용도로 무료다. 직접 추가 콘텐츠를 공유하면 오타·중복과 편집 권한 관리가 필요해지므로 만든 사람에게만 검색되게 한다.

## Reconsider when

- 한국 예능·드라마의 회차 누락이 반복적으로 확인되어 직접 추가가 기본 경로가 될 때
- 상업적 운영 등으로 TMDB 이용 조건이 맞지 않게 될 때

## Still-rejected alternatives

- 애니메이션을 쿨 단위로 나누기 — TMDB "Cours" 회차 묶음은 작품마다 있는지 보장되지 않는다; 사용자는 기수별 분리를 골랐다.
- 열어 볼 때 저장 — 둘러본 작품까지 "내 콘텐츠"에 쌓인다; 사용자가 거부했다.

- KOBIS — 영화만 다뤄 드라마·예능을 채울 수 없다.
- 직접 입력만 받기 — "실제 회차" 조건을 보장할 근거가 없다.
- 직접 추가 콘텐츠 공용화 — 중복·편집 권한 관리가 필요하다; 직접 추가가 잦아지면 재검토.
